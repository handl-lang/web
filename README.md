# `project/` — web

Docs for the `web` target live on this `project` branch, mounted as the
gitignored `project/` worktree; `main` stays a clean tree (ADR-0129 §1).

| entry | answers |
|---|---|
| `adrs/` | *why* — the decision, and what was rejected |
| `tasks/` | *who/what next* |
| `design/` | *how* — mechanism, named after its ADR |
| `notes/`, `reports/` | *what we found / measured* (dated) |
| `references.md` | *what we depend on* — foreign ADR ids + URLs |

Layout rule: ADR-0162 · ADR shape: ADR-0161 (both in `host/project`).

## Local entries

- `references.md` — the canonical platform ADRs this repo implements (0107, 0113–0117, 0121, 0137, 0143).

Published documentation (tutorial, how-to, reference, explanation) belongs to
the org `docs` repo, not here.
